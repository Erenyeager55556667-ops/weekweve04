# Weekweave

Money & Food planner, packaged as an Android app with Capacitor.

1. Upload all files in this folder to your GitHub repository (keep `.github/workflows/build-apk.yml`).
2. Open the **Actions** tab, choose **Build Android APK**, press **Run workflow**.
3. When it finishes, open the run and download **Weekweave-APK** (a zip containing `app-debug.apk`).
4. Unzip it on your phone and install the APK (allow installing from unknown sources if asked).

Keep `debug.keystore` in the repo: it keeps the signature the same so new versions install over the old one.
